# 💝 インプレッション機能強化: 内心・本心分析機能

## 🎯 **実装目標**
既存のインプレッション機能に**内心・本心分析**機能を追加し、より深いキャラクター理解を提供

## 💖 **新機能概要**

### **1. 内心分析モード追加**
- **💭 キャラクターの隠れた感情**: 表面には出さない内面の気持ち
- **🤫 言葉の裏にある本当の気持ち**: 発言の真意や隠された思い
- **💕 相手への本音**: ユーザーに対する真の感情

### **2. 新しい視点追加**
既存の3視点に加えて：
- **内心視点**: キャラクターの心の中で本当に思っていること
- **本音視点**: 建前の裏にある真の気持ち  
- **潜在感情**: 無意識レベルでの感情の動き

## 🛠️ **実装アプローチ**

### **Phase 1: API拡張**
```typescript
// enhanced-impression API に内心分析機能追加
const prompt = `...
【新しい分析要求】:
4. 内心分析: キャラクターの心の奥にある本当の気持ち
5. 本音分析: 表面的な発言の裏にある真意
6. 潜在感情: 無意識に抱いている感情

【視点例】:
- 内心の声: 「実は...」「本当は...」
- 隠された感情: 恥ずかしさ、嬉しさ、不安など
- 真の動機: 行動や発言の根底にある想い
...`;
```

### **Phase 2: UI強化**
```typescript
// 新しいアイコンと色分け追加
const getInnerHeartIcon = (perspective: string) => {
  if (perspective.includes('内心') || perspective.includes('本音')) {
    return <Heart size={20} className="text-pink-500" />; // 💕
  } else if (perspective.includes('隠れた') || perspective.includes('潜在')) {
    return <EyeOff size={20} className="text-purple-500" />; // 👁️‍🗨️
  }
  // 既存のアイコン...
};
```

- **心理的距離**: 相手との心の距離感
- **感情の変化**: 会話を通じた心境の変化
